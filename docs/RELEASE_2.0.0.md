# 2.0.0 发布验证

本版本整理统一启动、终端菜单与账号管理界面，保留生成、抗截断和账号调度算法。

## 连接与默认密钥

- 电脑：`http://127.0.0.1:8765/v1`。
- 同 Wi-Fi 手机：`http://电脑局域网IP:8766/v1`，与电脑入口同时启动。
- 两边默认 API 密钥都是 `mmdb`，已有自定义值不重置。
- 开源发布不包含个人外网配置、外网密钥、Google 凭证或真实账号数据。管理页仍仅限本机并使用独立随机管理令牌。

## 已完成的检查

- Node 自动化测试 482 项通过，覆盖原有生成协议、工具、取消、抗截断，以及新的局域网失败降级、并发重试、入口复用和权限限制。
- Windows 安装管理集成检查、便携更新检查、独立解压发布包检查通过。
- 使用未修改的已发布旧版更新器，检查源码更新、发布 ZIP 更新和固定安装更新，验证配置与后台可用性。
- Termux 引导的隔离检查通过；Bash 语法通过。未把 Windows 上的模拟检查当作 Android 真机验证。
- 账号页在 1280、390、360 像素宽度检查：三步教程、后台操作入口、账号列表和 OAuth 表单可见，无横向溢出或页面脚本错误。原有业务脚本和表单 ID 保留。
- 在运行中的网页后端并发调用电脑入口和局域网入口，两次真实短文本生成均返回 HTTP 200，响应内容符合预期；重复启用复用同一后台。此项由电脑访问两个地址，未使用手机真机。
- 发布 ZIP 校验与公开文件清单检查通过，未包含运行日志、用户配置或私人连接信息。

## 使用范围

局域网入口仅供可信私网：仍检查私网地址、允许网段、Host、Origin、API 密钥及生成路由。没有唯一私网地址或手机端口被占用时，本机继续运行；修正 `lan-config.json` 后再次启动可重试。

这些检查不保证 Google 上游、每一种安卓浏览器或省电策略始终可用。更新后重新打开终端菜单；网页模式需要在油猴确认脚本更新并刷新 AI Studio。
