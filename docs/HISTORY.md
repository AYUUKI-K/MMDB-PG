# 历史更新记录

以下按版本保留当时的行为和验证范围。当前安装与操作步骤见[使用说明](USAGE.md)。

## 1.7.3：简化连接与手动换号

移除邮箱读取、填写、候选记录，以及额度换号提醒、模型冷却和备用账号自动切换。Meow 激活完成后直接连接，每次使用一个页面；上游额度错误原样返回，后续手动请求不受本地冷却阻拦。保留生成取消、请求上下文变化保护及原有生成设置。

新版用户脚本清除旧邮箱候选记录；后台不再读写 accounts.json，固定管理器不再迁移它，旧配置中的 accountCooldownMs 被忽略。更新后需同步更新用户脚本并刷新 AI Studio。

## 1.7.2：自动识别邮箱与新对话激活

从原生账号按钮读取当前登录邮箱，匹配实际捕获的原生请求后自动连接；账号变化时先断开旧会话，读不到邮箱时保留手动输入。Meow 激活改为在当前标签页新建对话后发送，避免在旧对话累积问候；保留草稿保护、生成互斥与重复点击保护。

## 1.7.1：适配页面按需启用的会话验证

当前 AI Studio 页面在未启用 WAA 时可正常返回空验证串。执行器仅在同时观察到原生 GenerateContent 请求确实省略验证串后接受该模式，仍逐次调用原生验证入口；签名模式失败不会回退为空串。修复 Meow 已发出而面板仍等待激活的问题。

## 1.7.0：主题同步、面板与 RP 悬浮窗

默认读取每位用户自己的酒馆美化，同步背景、文字、强调色、边框、字体栈、圆角和阴影到 AI Studio 面板与悬浮窗。通过同一用户脚本的本地存储同步，无需修改酒馆核心。重做浅深色面板、手机状态条和设置布局；移除实际模型核验与重复技术日志，提供活动清空。工具读取输入与原生续写转为常规开关，保留原配置和默认关闭。新增跨标签页的置顶悬浮窗及普通小窗回退；关闭后恢复原面板。新增一键发送 Meow 激活会话，包含草稿保护、重复点击锁定和生成互斥。

## 1.6.0：按额度切换账号

账号识别进一步改为手动确认的主邮箱。不同邮箱复用同一 Google 账号位不再混用冷却，同一邮箱跨浏览器仍共用冷却并限制重复连接。面板记录最近使用的邮箱作为候选，新页面或账号上下文变化后重新确认；邮箱与各模型冷却保存在本机 accounts.json，重启与固定管理器更新后保留。公开健康接口及诊断文件不记录邮箱，页面日志只显示掩码。旧脚本保留账号位兼容，需更新后才能使用邮箱识别。

将最初的轮询与按队列负载分配调整为持续使用当前账号。并发请求继续在当前页面排队，额度受限后才使用已连接的备用账号；旧账号冷却结束、新账号接入都不会主动抢回请求。日常可只保持一个账号在线，用完后手动换号、发送 hi、确认邮箱，再重新发起请求，无需预先登录全部账号。

Google HTTP 429 与 RPC code 8 均记录当前账号、当前模型的冷却，默认 15 分钟，可通过 accountCooldownMs 调整。HTTP 429 只在初始请求尚无上游数据时自动转交备用账号；RPC code 8 保留本次错误，在下次请求选择可用账号。已有输出、输入读取已完成或续写中的请求不跨账号重放；保留原请求总时限与取消行为。

面板日志区分当前和备用页面，/v1/status 增加账号策略与 active 状态。无备用时提示手动切换步骤。本版不读取 Google 密码、不内置自动登录浏览器，.env 文件加入 Git 忽略规则。使用步骤和账号位识别边界见[账号使用与切换](USAGE.md#账号使用与切换)。

## 1.5.0：合入便携菜单版

合入 1.5.0 便携菜单版，包括便携菜单、续写完整性检查、模型观测和默认关闭的实验功能。当时的验证范围见[历史评审材料](AUTHOR_REVIEW.txt)和[实验记录](EXPERIMENTS.md)。

已有一键更新用户仍可在原管理菜单选 `2` 更新。下载包中的 Windows / Linux 入口兼容原固定管理器；直接解压后运行 `mmdb-pg/MMDB.cmd` 或 `bash mmdb-pg/mmdb.sh` 则进入便携菜单。更新后台后仍需安装 **1.5.1 浏览器用户脚本**，刷新 AI Studio 并重新发 hi 引导。

## 1.2.12：与新版 Playground 执行流程对齐

参考 Catiecli Playground Executor 2.12.0 执行流程：后续请求直接对后端 `binding` 计算 SHA-256、生成 fresh WAA proof 并发送，不再把完整聊天内容写入、同步或清空网页输入框。已有草稿不再阻止请求，生成、取消和重试都不会修改它；输入框尚未渲染也不阻止已完成引导的会话发送。

该版本首次仍需手动发 hi 捕获页面签名服务。抗截断工具、尾部用户提示词、思考强度、续传和超时策略不变，保留 1.2.11 的页面状态诊断。4A 长对话的断联改善效果尚未完成验证。

## 1.2.11：请求鉴权修正与断联诊断

- 每次请求重新计算能够从当前页面 Cookie 读取并明确识别的 SAPISID 签名段，不再始终重放上次发 hi 捕获的时间戳。读不到 Cookie 或遇到未知扩展格式时保留页面原值，不丢弃其他账号或会员请求头。
- 不再重放上次页面生成请求的 `x-goog-ext-*` 动态上下文头。保留页面真实的 API 标识、会员档位、账号选择与 visit-id。
- Google 连接失败时记录页面可见性、浏览器在线标志、页面定时器最长间隔和是否刷新签名；在菜单 `3` 可看到这些状态。不记录 Cookie、签名或聊天正文。
- 继续区分 Google 上游失败与本地 WebSocket 断开。没有增加重复生成、放宽安全检查或继续延长超时。

这些是已验证的请求处理修正，**尚未通过真实 4A 长请求证明能消除断联或缩短生成时间**。日志里的在线标志不等于 Google 一定可达，定时器长间隔也可能来自后台节流、忙碌或系统休眠，不能单独当作根因证明。此次没有修改抗截断工具或尾部提示词。

协议研究参考 [AIStudio2API 的鉴权与请求头说明](https://github.com/Mag1cFall/AIStudio2API/blob/main/docs/protocol.md)；后台计时器行为参考 [Chrome 官方说明](https://developer.chrome.com/blog/timer-throttling-in-chrome-88/)。

### 1.2.13 更新

4A 抗截断改为允许分段工具答复；无上游数据的连接失败允许一次重试，仍共用原有 600 秒期限。需更新后台和油猴脚本并刷新 AI Studio。已通过本地回归测试，实际 4A 断链修复效果仍待验证。

## 1.2.14：4A 回退基线

仅 gemini-4-argon 抗截断恢复 1.2.12 的单次工具尾部指令和工具描述，并关闭自动网络重试，避免长等待失败后重复消耗调用。3.8 Flash 和其他模型保留 1.2.13 行为。后台更新重启即可，1.2.13 油猴仍兼容；没有证据保证回退后成功率恢复，根因仍待定位。
