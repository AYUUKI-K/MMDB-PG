# MMDB-PG（喵喵电波）macOS 简易安装指南

本指南适用于在同一台 Mac 上运行反代、AI Studio 和酒馆的情况。

首次安装脚本选 **3**，日常启动选 **1**，更新选 **2**，停止时选 **5 更多 → 停止后台**。

## 1. 安装运行环境

### Node.js

打开 [Node.js 官方下载页](https://nodejs.org/en/download)，选择 **macOS 的 LTS 安装包（.pkg）**，按提示完成安装。项目要求 **Node.js 22 或以上**，安装时保留 npm 组件。

安装后重新打开“终端”，分别执行：

```bash
node -v
npm -v
```

两条命令都能显示版本号，且 Node.js 的主版本号不小于 22，即可继续。

### 浏览器和油猴

在 Chrome 中安装并启用 [Tampermonkey（油猴）](https://www.tampermonkey.net/)，按扩展提示允许用户脚本运行。后续安装脚本和打开 AI Studio，请使用这个浏览器。

## 2. 下载反代

[点击下载 MMDB-PG ZIP 安装包](https://raw.githubusercontent.com/AYUUKI-K/MMDB-PG/main/downloads/mmdb-pg-latest.zip)

1. 下载后双击 ZIP，完整解压。
2. 找到里面**包含 `mmdb.sh`、`package.json`、`tools` 等文件和文件夹的 `mmdb-pg` 文件夹**。
3. 在 Finder 中按 **⌘⇧H（Command + Shift + H）**，打开个人主文件夹。
4. 把整个 `mmdb-pg` 文件夹放进去，最终位置应为 `~/mmdb-pg`。

如果解压后外面还有一层文件夹，请移动真正包含 `mmdb.sh` 的那一层。已有旧安装时，不要直接覆盖原文件夹，更新方法见下文。

## 3. 启动菜单并安装脚本

打开 macOS 的“终端”，执行：

```bash
cd "$HOME/mmdb-pg" && bash mmdb.sh
```

进入菜单后，输入 **3** 并按回车。程序会安装所需依赖、启动后台，并尝试打开浏览器脚本安装页。首次安装需要联网，请等待操作完成。

在油猴页面中确认安装 **MMDB 本地桥**。

如果没有自动打开，或打开到了其他浏览器，请把下面的地址复制到装有油猴的 Chrome 地址栏：

```text
http://127.0.0.1:8765/local-pg.user.js
```

## 4. 激活 AI Studio

1. 打开 [AI Studio Playground](https://aistudio.google.com/prompts/new_chat)，登录可以使用 AI Studio 的 Google 账号。
2. 如果页面原本已经打开，安装脚本后先刷新。
3. 点击反代面板上的 **Meow**。
4. 等待面板显示 **本地已连接 / Google 已就绪**。

Meow 会在当前标签页新建对话并发送一次问候，点击前请先保存未发送的草稿。

## 5. 连接酒馆

在酒馆的 API 连接设置中，选择 **聊天补全 → 自定义兼容 OpenAI**，填写：

| 设置 | 内容 |
| --- | --- |
| API 地址 / Base URL | `http://127.0.0.1:8765/v1` |
| API 密钥 / API Key | `mmdb` |

刷新模型列表，选择可用模型，再发送一条消息测试。

以上为默认配置；如果修改过端口或密钥，请以菜单 **4** 显示的地址及程序目录中的 `config.json` 为准。这里的 `mmdb` 是本地反代密钥。

## 日常启动、更新和停止

以后打开“终端”，执行同一条命令即可重新打开菜单：

```bash
cd "$HOME/mmdb-pg" && bash mmdb.sh
```

| 菜单选项 | 用途 |
| --- | --- |
| 1 | 启动 / 继续使用 |
| 2 | 更新程序，并打开浏览器脚本更新页 |
| 3 | 安装 / 更新当前程序提供的浏览器脚本 |
| 4 | 查看状态、版本和连接地址 |
| 5 | 更多，可查看日志或停止后台 |
| 0 | 退出菜单，后台继续运行 |

**更新：** 先结束正在生成的回复，再选 **2**。程序更新后，在油猴确认脚本更新，然后刷新 AI Studio；需要时再次点击 Meow。最后退出并重新打开菜单，以加载新版菜单内容。

需要停止时，先结束生成，再选 **5 更多 → 停止后台**。选择 **0** 可退出菜单，后台会继续运行。

**使用期间：** 保持 AI Studio 页面和浏览器运行，避免 Mac 休眠或合盖。后台保活不能保证设备休眠后仍可生成。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 提示 `node: command not found` 或 `npm: command not found` | 安装 Node.js 后重新打开终端，检查 `node -v` 和 `npm -v`。 |
| 提示找不到目录或 `mmdb.sh` | 检查文件夹是否为 `~/mmdb-pg`，以及 `mmdb.sh` 是否直接位于该文件夹中。 |
| 脚本安装页只显示代码 | 确认当前浏览器已安装并启用油猴，再重新打开脚本地址。 |
| AI Studio 没有反代面板 | 确认油猴中的 MMDB 本地桥已启用，按扩展提示允许用户脚本运行，再刷新页面。 |
| 显示本地未连接 | 在菜单选 1 启动后台，再回到 AI Studio 刷新并点击 Meow。 |
| 本地已连接，但 Google 未就绪或生成失败 | 确认账号能正常使用 AI Studio、网络可访问该页面，再查看具体错误提示。 |
| 提示已有其他页面连接 | 结束生成，关闭旧的 AI Studio 标签页，再在要使用的页面中点击 Meow。 |
| 更新后面板仍是旧版 | 在油猴中确认脚本更新，再刷新 AI Studio；菜单 4 可核对版本。 |

反馈问题时，请附上报错文字、发生时间和菜单 4 的版本信息；不要发送 Cookie、账号凭据或 API 密钥。
