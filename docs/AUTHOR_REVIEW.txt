MMDB PG 1.5.0 — 便携菜单评审包

历史归档：以下保留 1.5.0 评审时的说明。当前安装、功能与操作步骤以 USAGE.md 和 INSTALLATION.md 为准。

本包用于源码评审与本地试用，包含完整后端、用户脚本源码、构建脚本、离线测试、启动脚本和许可证。

一、评审前说明

这是本地 1.5.x 代码线的完整快照，不是基于公开仓库 1.2.14 生成的增量补丁。版本号不代表已合入公开仓库的全部改动。请先对比再选择性合并，尤其注意页面请求绑定、会话验证、4A 工具提示词和网络重试策略的差异。

本地代码仍使用空网页输入框进行请求绑定；公开仓库已有直接 binding 执行流程。此次未将两种流程自动合并。

二、本地代码线的主要改动

1. 拆分模型能力目录、请求期限、续写、用量统计与诊断职责；浏览器消息区分连接、逻辑请求、轮次及重试，隔离迟到数据。
2. 抗截断工具交付加强正文、工具标识和终态验证；协议错误、混合输出和中途断流不会伪装成成功完成。
3. 提示词续写加入精确接缝去重、重复无进展检测，以及整次请求的显式输出预算。未设置输出上限时保留上游默认值。
4. 面板增加原生续写实验开关，默认关闭；保存到 config.json，生成期间锁定，显示目录支持模型及本次实际模式。
5. 新增固定合成提示词的 Playground 探测工具。强制工具调用、参数流式的候选字段实测未生效，正式生成不发送这些候选字段，面板不保留无效入口。

三、验证结果与边界

- 离线回归：200 项通过（包括便携菜单与模型观测回归），包括协议、续写、取消、超时、保活、设置持久化、探测互斥和异常终态。
- 真实 Playground：Gemini 3.8 Flash 与 Gemini 4 Argon 的候选 ANY / NONE 未强制或禁止调用；约一万字符的工具参数仍以一个完整参数帧返回。
- 原生续写：Argon 短请求成功，开启后诊断显示 native，验证后恢复关闭；完整跨轮长输出尚未实测。
- 新面板：独立预览验证了手机/桌面尺寸、浅深色主题、开关和生成锁定。当前使用者选择稍后更新油猴，尚未在其真实 AI Studio 页面完成新版面板刷新验证。
- 以上不能证明其他账号、模型或未来 Playground 版本具有相同结果。详细协议假设及样本见 EXPERIMENTS.md。
- 便携菜单已用 Windows PowerShell 5 实测官方源依赖安装、中文和空格路径、后台启动、重复启动、状态、停止和配置保留；Node.js 官方版本与校验值查询通过真实网络核验，安装向导采用模拟测试，未修改测试电脑的系统 Node.js。
- 未对 Linux / Android / macOS 做本轮真机安装测试。

四、试用方法

Windows：完整解压后双击 MMDB.cmd，按菜单先检测再安装依赖。缺少 Node.js 时选择 8 下载校验官方安装器。旧 Start.cmd 仍可使用。
Linux：准备 Bash、Node.js 22+ 和 npm，执行 bash mmdb.sh。
Termux：先执行 pkg install nodejs-lts npm，将包放到 Termux 主目录后执行 bash mmdb.sh。
首次启动通过 npm 安装 ws，需要联网。需要局域网入口时使用 Start-LAN.cmd / bash start-lan.sh。

后台就绪后访问 http://127.0.0.1:8765/local-pg.user.js?v=1.5.0 安装或更新用户脚本，再刷新 AI Studio，登录并发送 hi。自定义端口以启动信息为准。

开发验证：npm ci --ignore-scripts；npm test。
重新构建脚本：npm run build。
重新打包：python tools/package-release.py（Python 仅维护者打包时需要）。

五、分发范围

本包不包含用户 config.json、lan-config.json、密钥记录、会话、聊天、诊断日志、PID、原始网页 bundle 或 node_modules；首次运行会创建默认配置。发布前请保留 LICENSE、THIRD_PARTY.md 与 licenses/ 中的来源及许可说明。
