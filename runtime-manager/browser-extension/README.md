# MMDB 本机凭证助手

这个扩展为 MMDB 独立后端提供一键 Cookie 导入。它不执行生成，也不替代原版的油猴脚本。

1. 在已登录目标 Google 账号的 Chrome / Edge 配置文件中，打开 `chrome://extensions` / `edge://extensions`。
2. 开启开发者模式，选择“加载已解压的扩展程序”，选择本文件所在的 `browser-extension` 目录。
3. 双击项目的 **Manager.cmd** 或执行 `npm start` 打开账号管理；已打开的页面先刷新，再点击“连接浏览器扩展”。
4. 在扩展自己的窗口中核对本机管理地址，点击“连接此管理服务”。这一步不会读取 Cookie。
5. 回到管理页，确认 Google 账号序号，点击 **一键抓取并导入**。

以后在同一浏览器配置文件和同一份管理器数据目录使用时，只需第 5 步。管理服务或电脑重启后，连接身份保存在 数据目录的 `browser-bridge.json`，不必重新连接；浏览器扩展更新后若没有响应，在扩展管理页点重新加载，再回管理页重新检测。

重复抓取同一账号会更新已有凭证。运行时先验证账号邮箱，空闲时短暂停止生成服务，备份原凭证并写入新凭证，然后恢复原运行状态；启用开关、代理、额度冷却和资源记录保留。备份在私有目录 数据目录的 `credential-backups`。启动失败会尝试恢复原凭证；生成中请等待结束后再抓取。

多个 Google 账号共同登录时，序号是 AI Studio URL `/u/N/` 中的 N，默认 0。扩展读取当前浏览器配置文件的 Cookie，不读取其他配置文件或无痕窗口。没有登录时，请先在该浏览器登录 AI Studio。

权限为 `cookies`、`storage`、`https://*.google.com/*`、`http://127.0.0.1/*`。Google 登录 Cookie 跨 Google 子域共享，因此需要 Google 域权限；实际读取固定为 AI Studio 的 Cookie URL。扩展不申请历史、密码、调试、所有网站或内容脚本权限。

只有用户确认连接的管理服务，才能签发绑定本机地址、账号序号、60 秒有效期的一次性抓取请求。Cookie 由扩展直接交给该本机服务，不回传到页面、扩展存储或日志。运行时会联系 Google 验证并保存凭证；这不发送生成请求，新账号需在账号池中自行启用。

扩展按钮中的“断开所有管理服务”可以撤销扩展连接，已导入的账号凭证仍保留在 MMDB。Cookie 失效后需要重新抓取；本扩展不获取 OAuth refresh token。
