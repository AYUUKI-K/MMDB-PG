# MMDB Runtime Manager

独立的本机账号池与运行时控制台。负责凭证导入、Camoufox 隔离登录、轮换策略、额度冷却、运行时恢复和进程守护。MMDB 保留 OpenAI / Gemini 反代、工具读取与提示词续写，通过适配层使用此项目。

## 直接使用

Windows 双击 **Manager.cmd**；其他系统执行 `bash start.sh`。也可运行 `npm start`。控制台后台独立运行，关闭命令窗口或网页不会停止服务。

Windows 启动窗口会保留结果，按任意键关闭。若没有看到浏览器页面，复制窗口里的本机管理地址打开；浏览器启动失败会显示提示，不会直接闪退。

全新目录需要 Node.js 22+，没有 npm 第三方依赖：

```sh
npm run install-runtime
npm start
```

Manager.cmd / npm start 首次会自动准备固定版本运行时；也可按上述命令提前安装。

0.2.0 增加独立“调用与诊断”页面：调用列表、单次时间线、账号切换原因、时延与已报告用量、运行恢复事件、组合筛选、分页和脱敏 JSONL 导出。默认保留 7 天 / 100 MiB，页面可配置。日志字段白名单不保存正文、图片内容、地址或凭证；账号使用本机稳定代号，导出再次匿名化。集成方通过 pool.diagnostics.record 写入同一私有目录。

在网页中导入凭证或点“用 Camoufox 添加账号”，然后启用账号并启动生成服务。管理入口只监听 `127.0.0.1`，访问令牌位于 URL 片段，并在加载后移入当前标签页会话存储。不要分享管理链接。

## 账号池与 Camoufox

- 默认“优先用完当前账号”；也可改为“每个新请求轮询账号”。池成员与上游当前启用账号分开记录。
- 仅在本次逻辑请求尚未收到任何有效事件时，针对明确的额度或权限错误尝试下个账号；本机 API Key 拒绝不会误判为 Google 账号过期。
- 一旦收到有效事件，多阶段生成和续写保持同一账号。部分输出、连接中断和不确定错误不自动重放。
- 冷却按模型保存，优先采用上游返回的期限；无期限时使用 1 至 30 分钟的退避。额度不会被重置，所有账号不可用时返回错误，等待冷却或重新登录。
- Camoufox 可用于隔离登录并保存凭证，也可选为后台会话验证引擎。登录由用户完成，不自动填写密码或处理验证码。
- 默认 SpiderMonkey 不需要常驻浏览器。Camoufox 后端会使用后台浏览器，首次由固定版本运行时准备所需文件。切换失败会尝试恢复原后端。

所有生成阶段共享操作锁；导入、切换后端、启停账号及登录会在有逻辑请求时拒绝执行。多个管理入口共享持久状态，不会各自轮换到不同账号。不要绕过控制台在上游原始管理页修改账号启用状态。

## 无人值守

Windows x64 的账号页提供“从本机 Chrome 导入（含 OAuth 续签）”，按邮箱调用已校验的固定版本运行时获取材料，并核对 Google 身份后保存。已有账号可点“获取 Chrome OAuth”原位更新，保留启用状态和额度记录。令牌不经过管理网页，临时材料在结束时清理；未找到、过期或设备绑定不匹配时提示失败。普通 Chrome / Edge 扩展抓取仍只导入 Cookie；保存 OAuth 也不保证永久续签或跨设备续签。

账号页显示保存的认证类型与最近实际验证记录。“验证登录”读取上游权益和模型目录，不发送聊天；上游可以用已有 OAuth 材料或本机 Chrome 来源恢复认证。后台只对已识别续签来源的失效账号，在空闲时尝试，失败至少间隔 10 分钟，连续 3 次失败后暂停。Cookie-only 不代表可永久自动续签；需要时重新登录或导入。成功验证保留模型额度冷却。

未就绪恢复在空闲且持续失败 60 秒后进行，每小时最多 3 次，不对登录失效或额度冷却反复重启。管理器和 MMDB 共享 15 秒检查窗口，管理登录在各进程内复用，未变更的账号池配置不重复写盘。恢复策略和验证记录跨进程重启保留。

运行时异常恢复默认开启，定期检查并以退避方式重试。控制台可开启独立进程守护：恢复控制台进程；配置了 MMDB 适配器时，也恢复意外退出的独立模式 PG。手动停止生成服务会保存停止意图；手动停止 MMDB 会暂停 PG 守护。

Windows 登录自启动默认关闭，可在控制台开启。只在当前用户登录后启动隐藏后台，不需要管理员权限。关机、休眠、断网和 Google 要求重新认证期间无法保证服务。

## 数据目录与独立分发

默认数据目录为本项目的 `.runtime/`。复制 `manager.config.example.json` 为 `manager.config.json` 可指定其他目录：

```json
{
  "dataDirectory": "D:/your-private-runtime"
}
```

当前 MMDB 工作区已将本机配置指向原 `.headless/`，没有复制或重新导入凭证。`manager.config.json` 是本机配置，不随包分发。若需要移动此项目，保留该配置的正确数据路径，并更新 MMDB 的模块引用；不要同时维护两份独立账号池。

此目录有自己的 `package.json`、启动入口、测试、扩展和许可证，可以独立拷贝、打包或建立仓库；核心模块不导入 MMDB。现在仍在同一工作区维护。`npm pack --ignore-scripts` 仅打包 `files` 白名单中的源码，不包含本机配置、凭证或下载的程序。

`integrationModule` 是可选的本机适配器文件路径。模块导出 `createIntegration()`，返回 `backend()`、`status()`、`start(lan)` 和 `stop()`；移除该配置后控制台不依赖 MMDB。当前适配器在 MMDB 的 `tools/manager-integration.mjs`。

## 验证与边界

执行 `npm test` 验证账号池、冷却、绑定、回滚、授权和守护设置；MMDB 根目录的测试另外覆盖反代流、取消和跨账号切换计数。

Windows 本机已验证 Camoufox 后端使用现有凭证生成 `MMDB_HEADLESS_OK`（`gemini-3-flash-preview`），随后恢复 SpiderMonkey。最初验证仅使用一个真实账号，多账号额度耗尽切换使用模拟上游测试；没有声称完成真实多账号额度耗尽实测。

凭证是受本机目录权限保护的明文文件，Cookie 可能失效，不承诺永久无人值守。运行时固定为 [AIStudio2API v0.2.18](https://github.com/Mag1cFall/AIStudio2API/releases/tag/v0.2.18)，其许可在 `licenses/`。Camoufox 由该运行时按需从官方发行源下载，不随本项目分发。

本机另外已验证 PG 与 AIStudio2API 进程分别意外退出后的自动恢复，以及手动停止跨守护周期保持停止。恢复后通过 MMDB 生成成功，合成读取保持开启且只派发一次请求。
